# 📄 Professional CV Website

A lightweight, clean, and fully responsive personal CV website built using core web technologies.

---

### ✨ Features
*   **Pure Design:** Built with 100% clean HTML and CSS.
*   **Fully Responsive:** Designed to look great on mobile and desktop.
*   **Professional Palette:** Uses a modern dark blue.
*   **Fast Loading:** Optimized for performance with no external libraries.

---

### 🛠️ Tech Stack
*   **HTML5:** Structured semantic content.
*   **CSS3:** Custom styling, Flexbox for layout, and Media Queries for responsiveness.
*   **GitHub Pages:** Free and secure hosting.
